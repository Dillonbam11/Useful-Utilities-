This repository contains bookmarklets all you need to do is copy the code and paste it into the url of a bookmark here is the step by 
step if you have never done this kind of thing before:

Tutorial:

**Step 1.** Make a bookmark of this page ( or any page ) On safari you click the share button in the top right then click “Add To Bookmarks”. On 
Google Chrome I think you click the star button ( it is called a favourite but it does the same thing), with Microsoft Edge you click the 3
dots then click add to favourite, on Firefox, I think you click a star on the address bar ( I do not use Firefox if u couldn’t tell).

**Step 2.** Name the bookmark something that is not suspicious but you know what it is.

**Step 3.** Edit the bookmark’s URL usually by right clicking on PC or holding it down on mobile, then click edit.

**Step 4.** Copy the code for one of the Bookmarks and Paste it into the URL field.

**Step 5.** Click the bookmark like you normally would to open a bookmark and it has ran the Bookmark.

**Step 6.** Now you have added the bookmarklet.
